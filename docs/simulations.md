# Simulations and scientific validation

The simulator returns noisy observations, their exact standard deviations, latent draws, and
known $\Sigma_{\text{true}}$:

```python
sim = simulate_measurement_error(
    n_cells=5000,
    n_features=30,
    covariance="block",
    noise="gene_cell",
    random_state=19,
)
```

Available covariance families are block, low-rank, sparse, and diagonal. Noise can vary by
gene, cell, both, or independently for each cell-feature pair.

Validation reports relative Frobenius error, spectral error, correlation RMSE, principal
subspace angle, and likelihood. Recovery tests use tolerances rather than exact equality.

The executable notebook and `examples/ground_truth_demo.py` compare naive, corrected, dense
MLE, and factor estimates against the same known truth. This is the primary acceptance test:
measurement-error awareness must improve recovery in a regime where the assumptions hold.

## Committed experiment

For the seeded 1,500-cell, 10-feature experiment, relative Frobenius errors were 0.441 (naive),
0.099 (corrected), 0.080 (MLE), and 0.083 (rank-2 factor). Correlation RMSE values were 0.174,
0.047, 0.035, and 0.030 respectively. Both iterative models converged. The exact JSON and plot
are committed under `results/` and regenerated by the example script.
